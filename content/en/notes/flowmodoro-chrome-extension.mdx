A fun small thing I shipped recently.

A while ago I wrote about [Flowmodoro](/en/posts/from-pomodoro-to-flowmodoro), a focus method I've been using instead of Pomodoro.

I'm still using it daily, both for work and hobbies.

I found that the best format for me is a browser plugin. It's just easier when the timer lives exactly where I work.

So I built and published a tiny Chrome extension for it.

👉 [Flowmodoro on the Chrome Web Store](https://chromewebstore.google.com/detail/flowmodoro/cpeoaekaeofeohmodjcambjfegooabli)

It's intentionally simple.
Mostly static HTML.
No complexity.
Just a tool that does one thing well.

Built it for myself first.
Published it because maybe others will find it useful too.

I love tiny software like this.
