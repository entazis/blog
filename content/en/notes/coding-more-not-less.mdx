Since AI agents became a thing, I realized I'm *coding* much more.

Not just because more code is being generated, but because I'm spending more **time in a coding mindset**.

When coding can start with simply specifying tasks, I end up doing it everywhere. On a bus. Between meetings. In small pockets of time that previously felt unusable.

Agents in the cloud run, generate PRs, and I review them, merge them, or ask for changes.

In a previous note I described this feeling as "[coding as management](/en/notes/coding-feels-managerial-now)." Instead of writing every line, I'm directing, reviewing, iterating.

What surprised me is that this didn't reduce the time I spend coding. If anything, the opposite happened.

My work sessions are longer now. I put in more hours than before.

Maybe it's the excitement of the productivity boost. Or maybe once coding becomes a continuous managerial loop, it's harder to step away.
